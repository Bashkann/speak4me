# Animation credits

Speak Four's rounded green buddy is an original, deliberately simple inline SVG character created for this project. It does not use or imitate any brand character artwork.

The small Lottie effects are temporary, replaceable placeholders from [LottieFiles/test-files](https://github.com/LottieFiles/test-files). The repository states that everything under `data/` is dedicated to the public domain under CC0:

| Local file | Upstream source | Usage |
| --- | --- | --- |
| `src/assets/lottie/search-orbit.json` | [`data/properties/position-ease.json`](https://github.com/LottieFiles/test-files/blob/main/data/properties/position-ease.json) | Searching accent |
| `src/assets/lottie/celebration-star.json` | [`data/shapes/star-round.json`](https://github.com/LottieFiles/test-files/blob/main/data/shapes/star-round.json) | Celebration accent |
| `src/assets/lottie/loading-color.json` | [`data/properties/color-ease.json`](https://github.com/LottieFiles/test-files/blob/main/data/properties/color-ease.json) | Loading accent |

The Lottie renderer is [`lottie-react`](https://github.com/LottieFiles/lottie-react), distributed under the MIT License. Lottie files and the player load only for moods that use an effect and never autoplay when the user requests reduced motion.
